# Wumpus World — Cyber Neon Edition

A responsive, neon-styled Wumpus World playable on phone, tablet, laptop, and desktop. Survive pits, hunt the Wumpus, grab the gold, and escape with intuitive touch and keyboard controls.

## Play
Open `index.html` in any modern browser. No build step required. For local dev, you can also serve the folder:

```bash
python -m http.server 8000
```

## Controls
- **Move**: Arrow keys / WASD / tap the neon pad.
- **Rotate**: Q / E or the circular pad buttons.
- **Shoot**: Space or ✦ button (one arrow per run).
- **Pick up**: F or ⬒ button when standing on gold.
- **Reveal & hints**: Toggle hints or reveal the board for teaching/demo.
- **Win condition**: Pick up the gold and return to the starting square.

## Features
- Adjustable grid size (4x4 to 8x8).
- Randomized worlds with pits, one Wumpus, and one gold bar.
- Sense readouts (stench, breeze, glitter), bump detection, and Wumpus scream feedback.
- Mobile-first layout with large tap targets and neon cyberpunk styling.
